# دليل استخدام وتثبيت قالب سينمانا ووردبريس (Cinemana TV WordPress Theme)

هذا المجلد يحتوي على الهيكل الكامل لقالب ووردبريس (WordPress Theme) مخصص ومتوافق بالكامل مع **شاشات التلفزيون الذكية Android TV** ويدعم التعديل والسحب والإفلات عبر **Elementor**.

---

## 📂 هيكل ملفات القالب:
1. `style.css` - ملف التعريف الأساسي للقالب لووردبريس (يمنع حدوث خطأ "يفتقد ملف التنسيق style.css").
2. `index.php` - الصفحة الرئيسية الحاضنة للتطبيق والمحتوى.
3. `functions.php` - ملف إعدادات القالب، وهو المسؤول عن استيراد ملفات جافا سكريبت وتنسيقات React كـ ES Module مدمج، ويدعم تسجيل عنصر Elementor تلقائياً.
4. `header.php` - الرأس الأساسي النظيف المتوافق مع كامل الشاشة.
5. `footer.php` - التذييل الأساسي.
6. `widgets/cinemana-tv-widget.php` - كود عنصر Elementor المخصص الذي يتيح لك إضافة شاشة التلفزيون في أي مكان بالصفحة.
7. `assets/` - المجلد الذي يجب وضع ملفات بناء تطبيق React بداخله.

---

## 🛠️ خطوات دمج وتجهيز القالب للرفع (ثواني معدودة):

### الخطوة 1: بناء التطبيق (Build)
قم ببناء التطبيق في مشروع React الخاص بك للحصول على ملفات الـ JS والـ CSS النهائية عبر تشغيل الأمر:
```bash
npm run build
```
سينتج عن ذلك مجلد باسم `dist` وبداخله مجلد `assets`.

### الخطوة 2: نسخ الملفات إلى مجلد القالب
1. أنشئ مجلداً جديداً باسم `assets` داخل المجلد `/wordpress-theme-cinemana/` إذا لم يكن موجوداً.
2. اذهب إلى المجلد المترجم `dist/assets/` وابحث عن الملفين الرئيسيين:
   - ملف الـ JavaScript (مثال: `index-d83a1b24.js`) -> انسخه وضعه داخل `/wordpress-theme-cinemana/assets/` وقم بإعادة تسميته ليصبح **`index.js`** فقط.
   - ملف الـ CSS (مثال: `index-e23fa2c1.css`) -> انسخه وضعه داخل `/wordpress-theme-cinemana/assets/` وقم بإعادة تسميته ليصبح **`index.css`** فقط.

### الخطوة 3: ضغط القالب إلى ملف ZIP
قم بضغط مجلد `wordpress-theme-cinemana` بالكامل (بما يحتوي عليه من `style.css` و `index.php` و مجلد `assets` ومجلد `widgets`) ليكون بصيغة **`wordpress-theme-cinemana.zip`**.

---

## 📥 طريقة التثبيت في ووردبريس:
1. اذهب إلى لوحة تحكم ووردبريس -> **مظهر (Appearance)** -> **قوالب (Themes)** -> **أضف جديد (Add New)**.
2. اضغط على **رفع قالب (Upload Theme)** ثم اختر ملف **`wordpress-theme-cinemana.zip`** الذي قمت بضغطه.
3. اضغط **تنصيب الآن (Install Now)** ثم اضغط **تفعيل (Activate)**.

مبارك! سيعمل القالب الآن بنجاح 100% دون أي أخطاء، وسيعرض تطبيق سينمانا التلفزيوني الرائع فوراً بكامل أناقته وتوافقه مع ريموت التلفزيون وكيبورد التلفزيون التفاعلي!
